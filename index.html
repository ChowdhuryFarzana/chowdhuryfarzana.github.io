Student Response Interpretation Using BERT

NLP Course Project (NLP 341)

This project asked two questions: can a fine-tuned BERT model tell whether a student's answer to a science question is correct, and do its attention weights point to the words that matter? I fine-tuned BERT-base on SciEntsBank (about 11K student responses to 197 science questions across 15 domains) for correct/incorrect classification. I evaluated it on three increasingly hard test sets: unseen answers, unseen questions, and unseen domains. I then visualized the [CLS] token's attention for correct and incorrect answers. Class imbalance pushed the model toward predicting "incorrect," and attention focused on content words in the question without clearly separating right from wrong answers. This result motivated my interest in looking deeper inside transformers. Next steps include adding the reference answer as input and trying 3-way labels.

Tools: Python, BERT-base (fine-tuning), SciEntsBank, attention visualization · View slides →
